# 🌍 Conversor Global de Moedas

Aplicação web desenvolvida para conversão de moedas internacionais em tempo real, utilizando **HTML, CSS e JavaScript puro**, com consumo de uma API pública de câmbio. O projeto tem foco em simplicidade, usabilidade e aprendizado frontend.

🔗 **Acesse o site:**  
https://dsilvaoficial.github.io/conversor-global-moedas/

---

## 📌 Sobre o projeto

O Conversor Global de Moedas permite ao usuário converter valores entre diversas moedas de diferentes regiões do mundo, como América, Europa, Ásia, África e Oceania. Os dados de câmbio são obtidos em tempo real através da API **open.er-api.com**, garantindo valores atualizados.

O projeto foi criado com o objetivo de praticar:
- Consumo de APIs
- Manipulação do DOM
- JavaScript assíncrono (async/await)
- Organização de código frontend
- Publicação de projetos no GitHub Pages

---

## 🚀 Funcionalidades

- ✅ Conversão de moedas em tempo real
